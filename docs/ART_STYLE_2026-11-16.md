# CityMate 美术与助手形象

日期：2026-11-16。

## 本轮调整

- 全站底色从冷灰调整为浅暖纸色，保留橙色主按钮、白色业务卡片和现有线性图标。
- 探店标题、笔记空状态及优惠券空状态加入少量装饰 emoji；装饰对辅助技术隐藏，不改变标题和按钮的可访问名称。
- AI 助手命名为“小橙”，身份为“AI 城市搭子”，增加原创橙子形象。接入介绍区、聊天头部、回复头像与手机问答入口。
- 常用提问配餐饮、优惠券、提示和订单图标，文字仍是实际问题，不引入假评价、假服务承诺或假进度。
- 手机入口保持单行；介绍插图缩小到 56px，避免挤占输入区域。保留减少动态效果偏好、焦点样式和明确的 AI 身份。

## 范围

只修改前端表现与隔离浏览器验收脚本，未修改模型接口、提示词、权限、领取确认或数据库。无需重建 Java 包。本轮不自动启动 Docker，不包含真实模型回答质量或线上性能结论。

形象来源及素材说明见 [素材说明](../frontend/assets/mascots/README.md)。

## 验证

- 前端单元测试：91 项通过。
- JavaScript 语法检查通过；Vue 模板编译无警告。
- AI 浏览器交互 12 项通过，包含形象图片加载和 320px 宽首屏发送按钮位置；全站 50 组页面 / 视口与 8 项业务交互通过。
- 修复清空问答后残留滚动位置，让欢迎内容从顶部显示。
- 使用独立无头浏览器和 API 夹具验证，不操作用户现有浏览器，不执行真实领券或付款。
- 浏览器结果与截图：`target/ai-journey-checks/`、`target/consumer-ui-checks/`。具体数量以各目录最新 `results.json` 为准。
