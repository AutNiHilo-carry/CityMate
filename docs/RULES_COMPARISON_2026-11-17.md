# 券限制前置与小橙店铺对比

日期：2026-11-17。

## 已完成的用户路径

1. 优惠券列表及店铺详情复用的券卡显示“用券前确认”，不用先展开原文才能注意到限制。
2. 从规则原文中摘录使用门槛、适用时间、预约要求与叠加限制；相同摘录合并标签，保留否定、例外和原句。
3. 原文未明确说明的项目显示“待确认”，不是“无门槛”“无需预约”或“随时可用”。原始规则仍可展开查看。
4. 小橙一次返回至少两家店时，可以展开“对比前 N 家店铺”（最多三家），对照人均、商圈／位置和本次已返回的券信息。
5. 对比按原工具返回顺序展示，不作为评分排名，不推测距离、实时营业、余位或优惠后的最终人均。券信息只按同一 shopId 关联；没有信息提示继续查券，不断言店铺无券。
6. 对比中可继续查某家店的券，沿用现有只读查询和领取确认路径。

## 实现边界

这是保守的原文摘录，不是已经完成券规则字段结构化。当前数据库仍以自由文本为主，摘录无法覆盖所有语言表达：宁可提示待确认，也不把没有识别到等同于没有限制。规则不是可执行资格判定；最终仍走服务端预览、权限、资格、最新规则复核与本人确认。

新增 `frontend/scripts/voucher-rules.js`；复用券卡组件和 Agent 工具观察结果。没有更换 Agent 框架、修改后端依赖、生成模型排名或新增模型请求，不需重建 Java 包。本轮不改变数据、券库存、付款或订单。
