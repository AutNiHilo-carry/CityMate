# RAG 回答证据复核

## 改动范围

之前只验证引用编号属于检索结果及资料版本仍有效，不能判断“回答说的退款条件是否出现在原文”。本轮为规则问答和包含知识引用的单 Agent 回答增加 `EvidenceSupportChecker`，不修改原检索范围、领券确认或交易流程。

生成后在独立上下文中调用同一已配置模型复核。输入只有用户问题、待展示答案按中文句末标点/分号/换行拆分的句子、所选引用和已有实时工具结果。复核要求整句受依据支持：付款不能推出退款、静态说明不能推出实时库存、不得倒置否定或编造金额时间。

模型报告全部支持时，服务端还要求：

- 每个句子有且仅有一项检查，编号不能缺失、重复、越界。
- 知识来源编号必须属于此次实际选择的引用，摘录必须逐字出现在对应原文中；引用须被实际使用。
- 混合查询的工具事实只能引用已有工具结果 JSON 中的摘录，不能借工具结果伪造知识引文。
- 不接受非布尔判定、伪造摘录、重复 JSON 键或尾随 JSON。

复核拒绝、超时、返回异常或格式不合格时丢弃整段草稿和引用，不降级展示未审核答案，也不触发自动重生成循环。Agent 标记为“需要澄清”也不能绕过已有知识引用的复核。完全不含知识引用的纯实时工具回答、无引用的补充提问暂不在本轮复核范围内。

## 时间、成本与版本

每次相关回答最多增加一次模型请求，复核温度为 0，网络预算最多 4 秒且不得超过当前请求剩余预算。规则问答增加约 25 秒的期限检查；Agent 继续使用既有 25 秒预算。数据库访问仍使用原超时机制，不能据此保证 HTTP 请求绝不超过 25 秒。

并发仍由现有两个槽位保护，复核占用同一个请求槽位，失败会释放。复核前后均再次检查全部提供过的知识版本；版本变化则丢弃答案。最后一次检查至客户端收到内容仍存在时间窗口，不宣称原子快照或彻底消除竞态。

## 不能据此宣传的能力

这是同一模型在单独上下文中的复核，不是独立模型或形式证明。逐字摘录检查只能证明“该段文字存在”，不能证明它在语义上支持回答；语义判断仍可能出错、受提示注入影响或重复生成模型的偏差，温度 0 也不保证事实正确。

当前一项句子检查只能指定一个来源，跨资料联合证明、礼貌性引导和复杂推导可能被误拒。超过 16 个分句或复核格式过长也会拒答，不会为了展示答案放宽验证。

本轮没有调用真实模型、测量误拒率/漏放率、Token 成本或延迟，没有声称退款误答已在真实环境消失。现有单元测试用模拟模型响应验证服务端协议和失败行为，不能代替复核质量评测。

## 验证与后续

新增测试覆盖支持/拒绝判定、编号和分句覆盖、伪造摘录、混合工具结果、无剩余预算不调用、复核异常、草稿不泄漏、并发槽位释放、复核期间版本变化，以及真实本地 HTTP 客户端发送温度/预算参数。接口保留原响应结构，资料不足仍向消费者返回通俗提示。

后续应在冻结的人工标注问答集上分别统计生成错误、复核误放、误拒及新增延迟，覆盖退款误检、否定条件、实时数量、商户范围、金额时间和正常改写；再决定是否调整复核模型、摘录协议或采用更严格的提取式回答。
