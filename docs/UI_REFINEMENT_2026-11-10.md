# 全站界面调整

日期：2026-11-10。范围为前端布局、样式与界面文案；没有改动模型、交易、权限、库存、消息及数据库逻辑，也没有重新打包 Java。

参考了 [大众点评公开产品资料](https://apps.apple.com/cn/app/id351091731) 和 [美团公开产品资料](https://apps.apple.com/cn/app/id423084029) 中的找店、评价、优惠和订单场景。本项目采用自己的桌面布局，没有复制它们的品牌、截图、商标或虚构服务承诺。

## 已验证与未验证

- 前端语法检查通过；31 项现有前端测试全部通过。仅同步调整了两处依赖旧提示语的断言，没有降低业务行为校验。
- 使用项目捆绑的 Vue 2 编译全站主模板、共享组件、助手与工程体验模板，无编译警告。
- 12 个页面路由壳及新增 CSS、助手 JS 返回 200，页面均加载新主题。该检查不能证明受登录保护的页面内容已经实际渲染。
- 原 Java 运行包不变。本轮未跑后端回归、未调用真实模型，也未实际领券、支付、登录或发布笔记。
- 浏览器专用连接不可用。随后使用 computer-use 检查时，被用户的物理 Esc 停止，之后没有继续操作浏览器。**本轮没有完成浏览器视觉、手机视口或完整点击验收。**

当前 Web 直接挂载前端目录，无需重建容器。浏览器按 Ctrl+F5 刷新后加载新样式。此前的后端与业务验证仍为各阶段历史记录，不与这次 UI 检查混为一组。

## 笔记与查询入口的后续修正

第三轮整理商户、优惠券和订单页：统一商户缩略图为方形，减少人均价格的过度强调；优惠券将售价独立到左侧金额区，规则、面值及限时库存放在右侧，不改领取判断与事件；不可领取时使用灰色金额区。手机端领取按钮放在规则下方，订单编号允许换行，状态标签和金额保持完整。补充键盘焦点和减少动画偏好的样式。再次通过 31 项前端测试与 Vue 模板编译，视觉效果仍待浏览器验收。

第二轮进一步调整首页信息层级：标题区取消大卡片背景，分类入口使用低饱和分色；笔记改为无外边框图片流，收窄侧栏，使用下划线来源切换和心形点赞。详情页调整作者字号、正文边界及底部操作间距。继续保留网格的正常阅读顺序，不增加虚构互动数据。该轮前端测试仍为 31 项通过，全站 Vue 模板编译无警告，尚未完成浏览器视觉验收。

- 笔记列表改为竖图卡片、双行标题和紧凑作者栏，多图角标与点赞数来自真实数据。
- 详情页保留原图比例，增加上一张、下一张与照片计数，保留缩略图、关注、点赞和关联商户入口。
