# 个人主页恢复与确认弹窗

日期：2026-11-12。

## 修改

- 个人主页的签到天数与笔记列表分别加载。天数查询失败只影响签到区，不阻止笔记显示；不再用默认的 0 天冒充查询结果。
- 签到区可单独重新查询；请求序号阻止旧失败覆盖新结果。签到成功后的天数查询复用相同逻辑，仍保留已签到状态。
- 领券及取消订单确认弹窗打开后禁用背景交互。关闭时还原背景、滚动设置和触发按钮的焦点；过期的 nextTick 回调不能重新锁住已关闭的页面，销毁时释放资源。
- 手机首页四个快捷入口改为两列，避免最后一个按钮独占一行。
