# 选券、店铺与笔记发布的业务补全

## 已实现

- 优惠券卡可直接展开完整使用规则，旧数据中的换行转成普通文本展示，未登录也可查看规则。
- 店铺优惠与探店记录分别展示加载、错误、空结果和重试。探店记录按每页5篇继续加载，保留已加载内容并避免重复卡片。
- 店铺、个人及其他作者的笔记列表批量补全作者头像、昵称与当前用户点赞状态；分页增加稳定排序及参数边界。
- 发布页按当前账号保存本浏览器草稿。编辑后500ms自动保存，也可手动保存；再次进入时明确选择恢复或新写，避免覆盖从另一家店进入的新内容。
- 草稿保存标题、正文、店铺、照片顺序和发布未确认状态，不保存登录密钥或图片二进制。非法结构、过长内容和不允许的路径不恢复；存储失败显示提示，保留当前可编辑内容。
- 上传后可调整封面，右侧/下方实时预览笔记。店铺搜索保留已选择的店铺，即使它不在搜索第一页中。
- 发布前保存草稿；发布成功清除当前账号草稿。网络超时、服务端错误或成功响应缺少有效笔记ID时，提示先查看个人主页，阻止再次直接提交，刷新后该提示仍可恢复。用户明确核对后可继续编辑。
- 清空草稿需明确确认，仅清除本地内容和照片选择，不批量删除服务器文件。图片仍由原后端校验归属与可用性。
- 发布页适配桌面和手机，提供字数、保存状态、封面标识、预览入口及明确的错误提示；辅助跳转链接仅在键盘聚焦时显示。

本地草稿不会跨设备同步，清理浏览器数据会丢失。恢复的照片路径不保证服务器文件仍有效。发布结果提示不是服务端发布幂等机制，人工再次提交仍需先核对已有笔记。
