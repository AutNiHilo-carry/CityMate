# 第二轮全站 Debug 与 UI 调整

日期：2026-11-11。本轮保留现有单体架构和业务数据，仅修正前端交互与样式；后端执行独立回归，没有重新实现交易链路。

## 已修复

1. **热门 / 关注切换竞争**：原加载锁会跳过新请求，旧响应随后被当成新列表解析。增加请求序号及请求时的列表类型快照，过期响应和异常均不更新页面。
2. **笔记分页恢复**：失败后保留页码与已加载内容，重试清除旧错误；按笔记 ID 去重，避免相邻页重复渲染。切换列表时显示骨架，而非闪现“暂无笔记”。
3. **取消订单后状态陈旧**：取消成功后重置并强制查询订单，旧刷新请求不能覆盖新结果。取消执行中禁用重复入口。
4. **取消超时提示**：网络错误或 5xx 不直接解释为取消失败，提示“结果未确认，请先刷新订单核对”，不自动重投 POST。
5. **签到成功被后续查询失败掩盖**：签到写入成功即保留已签到状态；连续天数查询单独降级，避免再次提交签到。
6. **首页优惠缺少可领取字段仍被推荐**：仅推荐服务器明确返回 `orderable=true` 的普通券。真实资格、库存仍由预览和提交接口确认。

新增 `frontend/tests/audit-round2.test.js`：前 6 项复现测试修改前失败、修改后通过；另增加首页优惠可用性测试。前端测试总计 72 项通过。

## UI 调整

- 探店笔记采用白底、细边框和统一圆角；标题预留两行，作者与点赞区保持一致，桌面与手机共用。
- 提高作者、点赞和次级按钮的文字可读性；可点击按钮与禁用按钮不再呈现相同的灰色观感。
- 找店筛选区增加边界，统一选中颜色；分类、排序和笔记来源提供 `aria-pressed` 状态。
- 订单抬头采用浅灰底，补全已使用、取消、退款中的状态配色。
- 保留已有大图查看器、草稿、来源查看及确认领券流程。
