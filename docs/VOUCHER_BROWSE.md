# 优惠券搜索与筛选

优惠券页支持关键词、店铺分类（美食、KTV 等）和具体店铺组合筛选，并显示匹配总数、空结果与失败重试。搜索匹配店名、券标题与副标题；“清空筛选”恢复第一页。具体店铺选项随分类变化，只展示有上架券的店铺。

## 查询方式

旧版先分页取店铺，再逐店查询券，存在额外请求及按店铺分页而非按券分页的问题。新增只读接口直接在数据库连接店铺与优惠券，完成过滤、计数和分页：

- `GET /voucher/catalog?keyword=...&typeId=...&shopId=...&page=1&size=12`
- `GET /voucher/shops?typeId=...`

只返回 `status=1` 的券；未开始、已结束或无库存的限时券仍可浏览，但按钮不可领取。活动时间和库存从数据库实时读取，最终资格与库存仍由原领取接口判定。搜索结果不是库存预留，既有普通券与秒杀领取流程未修改。

参数使用 MyBatis 绑定。关键词最多100字，`%`、`_` 和 `!` 按字面匹配，不作为通配符；页码1至10000，每页最多20条，按券ID倒序。计数与列表分别查询，期间商品变更可能导致总数短暂不同。具体店铺选项最多200家，超出时显示提示，仍可输入店名直接检索全部券。

## 前端状态边界

- 新搜索重置结果和页码，旧请求不能覆盖新结果。
- 翻页沿用已提交条件，编辑但未提交的输入不会混入下一页。
- 更换分类清空原店铺选择；店铺选项也防止过期响应回填。
- 加载下一页失败保留页码，重试不重复追加已成功页面。
- 筛选条、券金额区、规则和操作按钮均有窄屏样式。
