# CityMate AI 助手页面

入口：[AI 助手](http://127.0.0.1:8080/assistant.html)，也可从顶部主导航进入。沿用现有 Vue 2.5.16、登录态、API 响应格式与橙色视觉风格。

## 使用方法

1. 打开页面。未登录时可查看介绍、常见问题和店铺范围；登录后才能发送问题，登录成功会回到助手页。
2. 默认查询平台公开规则。可搜索店名并选择店铺，再选择该店优惠券。店铺搜索最多展示当前搜索的前 20 家；没有目标店铺时缩小关键词。
3. 输入 2～200 字的问题，点击发送或 Ctrl+Enter。示例：SUCCESS 表示已经付款了吗？
4. 回答下方点击来源卡，服务端会复查来源当前版本，再在页面内展开原文。已更新、过期或撤回的来源会提示重新提问。

当前只使用已发布的知识；选择店铺不代表其资料已经入库。现有平台演示知识为 platform-claim-progress。没有明确资料时会显示未找到依据，而不会编造该店规则。

## 交互边界

- 每次问题独立检索，不向模型发送历史对话。当前页最多保留最近 10 条问答，刷新后清空；不是跨会话记忆。
- 提问中禁止重复提交和修改范围。重试保留原问题及原店铺/券范围，不会随当前选择静默改变。
- 异步切换店铺时丢弃旧优惠券响应，避免将另一店铺的券混入当前范围。
- 问答请求使用独立的 30 秒前端超时，其他原业务 API 仍保持 10 秒。没有自动重试和额外模型请求。
- 状态按 answered 和 status 区分；HTTP 200 / Result.success=true 不代表模型已作答。无资料、模型未配置、超时或上游繁忙均明确展示。
- 回答、问题、原文及错误按 Vue 文本插值显示，不渲染模型 HTML/Markdown。来源请求路径从合法 sourceKey 和版本构造，不信任模型提供的 URL。
- 没有浏览器端模型 Key，沿用服务器 .env。没有领券、创建订单、模型工具循环、Embedding 或 SSE；等待提示不代表真实逐步执行轨迹。

## 运行与验证

frontend 为开发 Nginx 的只读挂载目录，修改无需重建 Java。新增路由同时更新 dev/nginx.conf 和 deploy/nginx.conf；开发 web 容器已通过 nginx -t 并平滑重载。

在 frontend 目录运行 `npm run check`、`npm test`。本次 18 项前端测试通过，其中新增 6 项覆盖参数/Long ID、来源路径、状态语义、重复请求、店铺切换竞争与失败恢复。

另用项目实际捆绑的 Vue 2.5.16 编译主页面和助手模板，无编译警告；对内存 VNode 检查了匿名登录入口及恶意 HTML 作为文本输出。此检查不是浏览器布局、键盘和屏幕阅读器验收。浏览器控制通道不可用，本次未保存页面截图。

HTTP 检查确认 assistant.html、两个 JS 模块、CSS 及后端健康接口返回 200。Java 问答真实模型及来源的先前联调结果见 citymate-deepseek-live-verification.json。本次前端变更没有额外进行压测或模型准确率评测。
